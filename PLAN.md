# Roblox School — Project Plan

## Project Overview
**Project:** Roblox School  
**Goal:** Help jojo make money (passive income via content/product)  
**Type:** Content blog/diary — สอนทำเกม Roblox แบบ solo dev เป็นภาษาไทย  
**Target:** คนไทยที่สนใจทำเกมบน Roblox

## Project Description
รวบรวมข้อมูลพัฒนาเกม roblox แบบ solo dev แบบที่ทำโดยการใช้ mcp tool มาช่วย ทำเป็นเว็บที่มีการทยอยปล่อยบทความออกมาเรื่อยๆ เป็นเหมือน diary การสอนทำเกมเป็นภาษาง่ายๆ ใช้ภาษาไทยในการสื่อสาร ตัวเว็บสามารถสลับไปใช้ภาษาอังกฤษได้ รองรับ mobile responsive

## Key Features
1. **Content Blog/Diary** — บทความทยอยปล่อยเรื่อยๆ เกี่ยวกับการทำเกม Roblox
2. **Dual Language** — ภาษาไทย (หลัก) + ภาษาอังกฤษ (สลับได้)
3. **Mobile Responsive** — รองรับทุก device
4. **Solo Dev + MCP Tools** — เนื้อหาสอนการใช้ MCP tool ช่วยพัฒนาเกม

## Proposed Tech Stack
- **Frontend:** Next.js (App Router) หรือ Astro สำหรับ static blog
- **Styling:** Tailwind CSS (responsive)
- **Content:** MDX หรือ Markdown files
- **i18n:** next-i18next หรือ astro-i18n
- **Hosting:** Vercel / Netlify / Cloudflare Pages
